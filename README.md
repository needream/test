# 人物动作 GIF 表情包生成器

上传人物照片 + 输入文案，自动生成动作并导出 GIF 表情包。

## 功能
- 上传一张人物照片
- 输入几个字（如：你好、收到、不行、太开心了）
- 根据文案关键词匹配动作（挥手/点头/摇头/弹跳）
- 预览动画并下载 GIF

## 运行方式

```bash
python app.py
```

打开浏览器访问：

```text
http://127.0.0.1:7860
```

## 说明
- 这是一个无需第三方 Python 包的轻量 MVP（只用 Python 标准库启动网页）。
- GIF 编码使用前端 `gif.js`（CDN 加载）。
- 后续可升级为 AI 视频动作模型，让动作更自然、更复杂。
